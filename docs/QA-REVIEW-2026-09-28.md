# Hasil pemeriksaan UI dan Roro — 28 September 2026

## Lingkup

Login, Ringkasan/Event Terdekat, daftar dan editor Event, editor Event Internal,
picker tanggal/jam, simpan draft, dan alur Roro. Pemeriksaan memakai kode kerja
berdasarkan commit `5cad077`. Screenshot asli QA tidak tersedia di repository;
reproduksi mengikuti langkah yang diberikan dalam laporan QA.

Lingkungan: macOS, Node 22.22.2, React 19.2.8, Vite 8.2.2, Playwright 1.63.0
(Chromium), Worker asli melalui Miniflare dengan D1/R2 sementara. Tes browser
mencakup desktop serta lebar 320–390 px dan layar chat pendek hingga 300 px.

## Temuan tambahan

- **Roro: proposal lama masih dapat diklik setelah revisi.** Backend sudah
  menolak proposal lama, tetapi state UI belum diperbarui. UI kini menonaktifkan
  proposal pending sebelumnya saat proposal baru tiba. Reproduksi awal menunjukkan
  dua tombol konfirmasi; sesudah perbaikan hanya satu.
- **Roro: pesan lama hilang setelah stream berikutnya gagal.** Penanganan error
  menghapus seluruh pesan dengan ID sementara, termasuk pesan dari giliran yang
  telah berhasil. Kini setiap pengiriman memiliki ID unik dan hanya pesan gagal
  itu yang dikembalikan ke input. Pengiriman juga diblokir selama konfirmasi
  proposal berjalan agar mutasi tidak berbenturan dengan revisi.
- **Sesi melewati tengah malam.** Default jam 23 sebelumnya dibatasi ke 23,
  menghasilkan rentang yang keliru. Penambahan satu jam kini melewati 00 dengan
  benar; sesi berikutnya menggunakan tanggal berikutnya, termasuk pergantian tahun.
- **QPR maintenance.** Halaman QPR memang sengaja belum dirilis. Guard maintenance
  sebelumnya menyebabkan pelanggaran aturan hooks dan lint gagal. Komponen aktif
  sekarang berada di bawah wrapper maintenance. Tes UI disesuaikan untuk memeriksa
  halaman maintenance yang berlaku, termasuk tidak adanya kontrol pengisian.
- **Tes resize chat.** Pemeriksaan awal membaca ukuran viewport lama sebelum event
  `visualViewport.resize` diterapkan. Assertion kini menunggu perubahan layout;
  batas tinggi yang diperiksa tetap sama.

## Verifikasi

- `npm test`: seluruh 11 suite backend lulus, termasuk keamanan, event internal,
  streaming Roro, konfirmasi, audit, dan isolasi akses.
- `npm run typecheck`: lulus.
- `npm --prefix panel run lint`: lulus tanpa error; warning yang tersisa dicatat
  oleh lint pada komponen lama.
- `npm --prefix panel run build`: lulus.
- `git diff --check`: bersih.
- `npm --prefix panel run test:ui -- --reporter=line`: **36 tes lulus**.
  Mencakup UI, helper sesi, serta simpan/edit/reload draft publik dan internal
  melalui Worker dan D1 asli.

### Roro dengan provider sungguhan

Provider menggunakan konfigurasi lokal yang tersedia. Auth test memakai akun
fixture; Worker dan database sementara menjalankan implementasi asli. Input berupa
agenda QA sintetis. Tidak ada data produksi yang ditulis oleh pengujian ini.

Alur yang lulus:

1. Streaming menghasilkan respons dan proposal `create_internal_event`.
2. Permintaan revisi mengubah waktu dari 08.00–10.00 menjadi 09.00–11.00 WIB.
3. Konfirmasi proposal lama ditolak dengan 409.
4. Konfirmasi proposal baru berhasil.
5. Database berisi tepat satu draft internal dan nol event publik.

## Batas verifikasi

Laporan ini mencatat verifikasi sebelum deployment. Browser otomatis yang
dipakai adalah Chromium; Safari/Firefox dan konfigurasi produksi perlu smoke test
saat rilis. Pengujian ini memberi bukti untuk alur di atas, bukan jaminan bebas bug
untuk seluruh kombinasi data, browser, jaringan, atau respons model.
